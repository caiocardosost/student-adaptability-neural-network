# Neural network for predicting adaptability to distance education.

Project developed during graduation to classify the level of adaptability of students to online education using a neural network manually implemented with NumPy.

## Technologies

-Python
- NumPy
- Pandas
- Matplotlib

## Structure

```text
├── date/
├── src/
├── report/
└── README.md
```
## Features

- Data pre-processing
- Encoding of categorical variables
- Manual implementation of neural network
- Training with backpropagation
- Classification into 3 levels of adaptability:
  - Low
  - Moderate
  - High

## How to execute

```bash
pip install pandas numpy matplotlib
```

```bash
python src/student_adaptability_nn.py
```
